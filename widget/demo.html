📋 Embed Script

Cara Embed di Website Anda

Tambahkan kode ini sebelum tag </body> di website Anda.

<!-- vlivechat Widget --> <script> window.VLiveChat = { workspace: 'demo_workspace', // Ganti dengan workspace code Anda apiBase: 'http://localhost:3001', // Ganti dengan URL server Anda }; </script> <script src="http://localhost:3000/widget/widget.js" async></script>
